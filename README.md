# 1c8-doc — справочник по встроенному языку 1С:Предприятия 8.3 для Claude Code

Навык для [Claude Code](https://claude.com/claude-code): справочник по встроенному языку 1С:Предприятия 8.3, объектам
платформы, глобальному контексту, управляемым и обычным формам, системе компоновки данных и языку запросов. Модель находит
запись по имени функции, метода, свойства, события или значения перечисления и сразу видит синтаксис, параметры,
возвращаемое значение, где доступно (клиент, сервер, внешнее соединение), с какой версии платформы, английское имя и пример.

**Текста справки в репозитории нет**: права на него принадлежат фирме «1С». Справочник собирается один раз из синтакс-помощника
вашей установленной платформы — из четырёх файлов `.hbk` её каталога `bin`.

## Возможности

- **Сборка из платформы.** `build/build_docs.py` читает четыре книги синтакс-помощника: `shcntx_ru.hbk` (объекты и глобальный
  контекст), `shlang_ru.hbk` (операторы и типы), `shclang_ru.hbk` (формат модуля), `shquery_ru.hbk` (язык запросов) — и
  раскладывает их по каталогам в Markdown: одна запись — одна функция, метод, свойство или событие. Две сборки из одних и тех же
  книг дают одинаковый результат байт в байт. Страницу, которую сборщик не может разобрать, он называет и останавливается, а не
  пропускает молча.
- **Поиск по имени.** `doc8.py find` находит запись по русскому или английскому имени. Член объекта ищется вместе с именем
  объекта (`ТаблицаЗначений.Скопировать`), поиск можно сузить до каталога или файла (`--in`).
- **Поиск по словам.** `doc8.py search` находит записи, в которых есть все названные слова.
- **Оглавление.** `doc8.py list` показывает каталоги с числом файлов и записей, `INDEX.md` — оглавление справочника.
- **Доступность и устаревшее.** У записи есть поля `Доступность:` и `Версия:`, у устаревшей — `Устарело:` с тем, чем её заменить.

## Требования

- **Python 3.9 или новее.** Достаточно стандартной библиотеки, сторонние пакеты не нужны.
- **Книги синтакс-помощника** из каталога `bin` установленной платформы 1С:Предприятие 8.3. Сама платформа на этом компьютере
  не обязательна: четыре файла можно скопировать с другого.

## Установка

Скопируйте каталог `1c8-doc` в каталог навыков Claude Code: в `~/.claude/skills/` — чтобы навык был доступен во всех проектах,
или в `<проект>/.claude/skills/` — только в одном проекте. Затем соберите справочник.

### macOS и Linux

```bash
cp -R 1c8-doc ~/.claude/skills/
python3 ~/.claude/skills/1c8-doc/build/build_docs.py --src "<каталог с файлами .hbk>"
```

### Windows

PowerShell:

```powershell
New-Item -ItemType Directory -Force "$env:USERPROFILE\.claude\skills" | Out-Null
Copy-Item -Recurse 1c8-doc "$env:USERPROFILE\.claude\skills\"
py -3 "$env:USERPROFILE\.claude\skills\1c8-doc\build\build_docs.py" --src "C:\Program Files\1cv8\8.3.27.1936\bin"
```

Путь к `bin` подставьте свой: в нём номер вашей версии платформы.

Сборка идёт несколько секунд и заканчивается отчётом: сколько файлов и записей получилось в каждом каталоге. Каталог `bin`
сборщик только читает. Версию платформы для `INDEX.md` он берёт из имени каталога над `bin`, другую можно задать ключом
`--platform`. После обновления платформы справочник собирают заново той же командой.

Claude Code подключает навык сам: когда модели в работе нужно уточнить функцию или метод 1С 8.x, она прочитает `SKILL.md` и
воспользуется поиском. Команды можно запускать и вручную.

## Быстрый старт

```bash
D=~/.claude/skills/1c8-doc/doc8.py

python3 $D find СтрНайти                         # запись целиком, по русскому или английскому имени
python3 $D find ТаблицаЗначений.Скопировать       # член объекта — с именем объекта
python3 $D find Добавить --in ТаблицаЗначений     # или сузить поиск до файла объекта
python3 $D find КОНЕЦПЕРИОДА --in queries         # язык запросов
python3 $D search временная таблица запрос        # записи, где есть все слова
python3 $D list "objects/Система компоновки данных"
```

`find` печатает запись под строкой с файлом и номером строки, например `— global/Функции работы со значениями типа
Строка.md:441`. Если совпадений больше пяти, печатается их список: уточните имя объекта или каталог. Коды возврата: 0 — нашлось,
1 — ничего не нашлось, 2 — неверный вызов или справочник ещё не собран.

## Что в справочнике

| Каталог | Что там |
|---|---|
| `global/` | глобальный контекст: свойства, функции по группам (строки, даты, числа, файлы, XML, JSON, сеанс…), события приложения |
| `collections/` | массив, структура, соответствие, список значений, таблица и дерево значений, фиксированные коллекции |
| `objects/` | общие объекты: СКД, XML, XDTO и JSON, файлы и двоичные данные, HTTP, криптография, табличный и текстовый документ, метаданные, регламентные и фоновые задания… |
| `applied/` | справочники, документы, регистры, планы, задачи, бизнес-процессы, внешние источники, хранилища настроек |
| `forms/`, `forms-ordinary/` | управляемые формы (поле, таблица, группа, данные формы) и обычные |
| `enums/`, `values/` | системные перечисления и наборы значений (библиотека картинок, веб-цвета, цвета стиля) |
| `queries/` | объект `Запрос`, схема запроса, таблицы источников; синтаксис текста запросов — одним файлом |
| `admin/` | администрирование кластера, COM-соединения, Automation |
| `lang/` | выражения, операторы, примитивные типы, препроцессор, директивы, аннотации, формат модуля, режимы запуска |

Из книг платформы 8.3.27 получается 2 764 файла и 25 766 записей.

## Ограничения

- Сборщик проверен на книгах платформы 8.3.27.1936. В книгах другой версии может встретиться разметка, которой он не знает:
  тогда сборка останавливается, называет страницу и ничего не записывает.
- Справки F1 конфигуратора, английских книг, справки по типовым конфигурациям и БСП в справочнике нет, платформы 7.7 тоже.
  Ссылки «Методическая информация» сняты.
- Текст записей — как в синтакс-помощнике: сборщик ничего в нём не правит, а правка собранных файлов руками пропадёт при
  следующей сборке.
- Навык разрабатывался и проверялся в macOS на Python 3.9, 3.10 и 3.14. В Windows сборка не проверялась.

## Как разрабатывался навык

Навык написан моделями Claude в среде [Claude Code](https://claude.com/claude-code) под руководством человека за один день,
10 сентября 2026 года: 25 коммитов. Около 1 700 строк кода на Python и 109 тестов (86 — у сборщика, 23 — у поиска). Тесты в
комплект не входят: часть из них проверяет собранный справочник, а его в репозитории нет.

Сборщик строг: незнакомая метка раздела, неизвестный класс разметки, узел оглавления без страницы, два файла с одним именем в
каталоге — это отказ с адресом страницы, а не предупреждение. Так каждая особенность книг, найденная при сборке, стала правилом
с тестом, а не догадкой.

## Лицензия

Код навыка распространяется по лицензии MIT — см. файл `LICENSE`. Текст справочника, который собирается из книг платформы,
под эту лицензию не подпадает: права на него принадлежат фирме «1С». Собранный справочник нужен для вашей работы и в
репозиторий не входит — `.gitignore` его не пропускает.
