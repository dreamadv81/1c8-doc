# 1c8-doc — справочник 1С 8.3

Файлы markdown из четырёх книг синтакс-помощника платформы 8.3 (`shcntx`, `shlang`,
`shclang`, `shquery`). Индекса нет: скрипт разбирает markdown на лету, `INDEX.md` — оглавление
по каталогам, файл раздела (`<Раздел>.md` внутри каталога) — состав раздела.

## Сборка справочника

Текста справки в навыке нет: права на него принадлежат фирме «1С». Справочник собирается один раз
из книг вашей платформы — каталога `bin` её установки (в Windows обычно
`C:\Program Files\1cv8\<версия>\bin`):

```bash
python3 <навык>/build/build_docs.py --src "<каталог bin платформы>"
```

Сборщик кладёт каталоги справочника и `INDEX.md` в каталог навыка и печатает отчёт. Пока
справочник не собран, `doc8.py` отвечает кодом 2 и подсказкой с этой командой.

## Как искать

```bash
python3 <навык>/doc8.py find СтрНайти                        # запись целиком, рус. или англ. имя
python3 <навык>/doc8.py find ТаблицаЗначений.Скопировать      # член объекта — с именем объекта
python3 <навык>/doc8.py find Добавить --in ТаблицаЗначений    # или сузить до файла объекта
python3 <навык>/doc8.py find КОНЕЦПЕРИОДА --in queries        # язык запросов
python3 <навык>/doc8.py search временная таблица запрос       # записи, где есть все слова
python3 <навык>/doc8.py list                                  # каталоги: файлов и записей
python3 <навык>/doc8.py list objects/Система компоновки данных
```

`find` печатает запись под строкой `— global/Функции работы со значениями типа Строка.md:57` —
по ней запись открывается `Read` с `offset`; совпадений больше пяти — список `путь:строка Имя`,
уточняйте именем объекта (`Объект.Член`) или `--in`. Имя без точки ищется и как часть после
точки: `find Добавить` даёт все `*.Добавить`. `search` даёт по строке на запись, до 20 (`-n N`).
`--in` — каталог (`global`, `objects`, …), путь каталога (`objects/XML`) или имя файла без `.md`.
Коды: **0** нашлось, **1** ничего, **2** неверный вызов. Фразу из описания ищите `Grep`.
В каждом каталоге — файл `<Раздел>.md` (описание, `Состав:` — список его файлов); подразделы
каталога ищите через `INDEX.md`.

## Карта
| Каталог | Что там |
|---|---|
| `global/` | глобальный контекст: свойства, функции по группам (строки, дата, число, файлы, XML, JSON, сеанс…), события приложения |
| `collections/` | Массив, Структура, Соответствие, СписокЗначений, ТаблицаЗначений, ДеревоЗначений, фиксированные |
| `objects/` | общие объекты: СКД, XML/XDTO/JSON, файлы и двоичные данные, HTTP, криптография, табл. и текстовый документ, метаданные, DOM/HTML, регл. и фоновые задания… |
| `applied/` | справочники, документы, регистры, планы, задачи, бизнес-процессы, внешние источники, хранилища настроек |
| `forms/`, `forms-ordinary/` | управляемые формы (поле, таблица, группа, данные формы) и обычные |
| `enums/`, `values/` | системные перечисления и наборы значений (БиблиотекаКартинок, WebЦвета, ЦветаСтиля) |
| `queries/` | объект Запрос, схема запроса, таблицы источников; синтаксис текста запросов одним файлом — ключевые слова, функции и операторы |
| `admin/` | администрирование кластера, COM-соединения, Automation |
| `lang/` | выражения, операторы (`Если`, `Для`, `Попытка`, `Новый`, `Ждать`…), примитивные типы, препроцессор, директивы, аннотации, формат модуля, режимы запуска |
Число файлов и записей — в `INDEX.md` (у платформы 8.3.27 — 2 764 файла, 25 766 записей).

## Что читать по задаче
- **Модуль объекта или общий модуль**: функции — `global/`, объект — `find Имя`, члены — `find Имя.Член`; прикладной тип — `applied/<Вид>/`.
- **Управляемая форма**: `forms/Форма клиентского приложения/`, элементы — `forms/Поле формы/`, `forms/Таблица формы/`; данные формы — `forms/Данные формы/`.
- **Запросы**: текст запроса, ключевые слова, функции и операторы языка запросов — `queries/Синтаксис текста запросов.md`; таблицы источников — `queries/Таблицы запросов/`, объект `Запрос` — `find Запрос --in queries`.
- **СКД**: `objects/Система компоновки данных/`. **Операторы и типы**: `lang/`. **Перечисление**: `find ИмяЗначения` → `enums/`.
- **Формат выгрузки конфигурации, форм, макетов** — не этот навык.

## Чего здесь нет
- Платформы 7.7. Справки F1, конфигуратора, типовых конфигураций и БСП. Ссылок «Методическая информация» — сняты.

## Особенности источников
- У записи есть `Доступность:` (клиент/сервер/внешнее соединение), `Версия:` и, у устаревших, `Устарело:` («Не рекомендуется использовать, начиная с версии …» и чем заменить) — смотрите все три до вызова.
- У имени члена десятки записей (`Добавить` — 207): ищите с именем объекта.
- У метода с несколькими формами вызова — строки `Вариант:` со своими синтаксисом и параметрами.
- Текст страниц как в помощнике: конвертер ничего не редактирует; файлы собирает `build/build_docs.py`, правка руками пропадёт при следующей сборке.
